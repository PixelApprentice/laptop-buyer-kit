# Research prior art skill

1. Search maintained upstream repositories and official documentation; record date and canonical URLs.
2. Separate documented features from verified behavior and from assumptions.
3. Inspect exact license, bundled dependencies, update activity, test coverage, known issues and release artifacts.
4. Prefer upstream contribution or a licensed extension when appropriate; do not start a duplicate implementation without a decision-log justification.
5. For plug-ins/skills, inspect permissions, hooks, scripts, license, commit/tag, maintenance, and compatibility with Antigravity CLI.
6. Never label a tool open source merely because it is free to download.
7. Record unresolved questions and validation tasks rather than asserting a universal gap.
